### 🚀 Öne Çıkan Proje (Flagship Showcase)

#### 📝 [Full-Stack Blog Platform](https://blog-frontend-theta-six.vercel.app)
> Katmanlı mimari (Layered Architecture) ve ayrık (decoupled) istemci-sunucu yapısıyla geliştirilmiş, üretim ortamında koşan blog ve içerik yönetim ekosistemi.

- **Frontend:** React, Vite, TypeScript, Tailwind CSS, React Router v6, Axios (JWT Bearer Interceptors) — *Vercel Edge Network üzerinde canlıda.*
- **Backend & DB:** Node.js, Express.js, TypeScript, PostgreSQL (Neon Serverless), Prisma v7, Docker — *Render üzerinde konteynır olarak koşturuluyor.*
- **Kritik Mühendislik Çözümleri:** 
  - Render geçici dosya sistemi (ephemeral disk) sorununu aşmak için Multer + Cloudinary CDN entegrasyonu ile kalıcı medya yönetimi.
  - Multipart form yüklemelerindeki veri tutarsızlıkları için Zod preprocess ve defansif veri normalizasyonu.
  - Vercel SPA rewrites ile derin bağlantılarda (deep-linking) 404 sorunsuz yönlendirme.
- **Bağlantılar:** [Canlı Demo](https://blog-frontend-theta-six.vercel.app) • [Vaka Çalışması (Case Study)](https://berkaycelik.dev/projects/pulse) • [Portföy](https://berkaycelik.dev)

### 🛠️ Mühendislik Yaklaşımım & Odak Noktalarım

- 🏗️ **Temiz & Katmanlı Mimari:** Controller, Service ve Repository katmanlarını ayrıştırarak bakımı kolay, gevşek bağlı (loosely coupled) sistemler kurarım.
- 🔒 **Güvenlik & Doğrulama:** Çift JWT (Access & Refresh), Zod tabanlı şema doğrulaması, rol bazlı yetkilendirme (RBAC) ve IP tabanlı Rate Limiting standartlarını uygularım.
- 🌐 **Ağ & Sistem Temeli:** Cisco Network altyapım sayesinde TCP/IP, DNS, HTTP protokolleri ve sunucu-istemci mimarilerine teorik değil, temelden hakimim.
- 🤝 **Saha & Ekip Disiplini:** Decathlon bünyesindeki Spor Liderliği deneyimimden edindiğim iletişim, çevik kriz yönetimi ve sorumluluk alma reflekslerimi yazılım ekiplerine taşırım.
