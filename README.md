### 🚀 Featured Project (Flagship Showcase)

#### 📝 [Full-Stack Blog Platform](https://blog-frontend-theta-six.vercel.app)
> Production-grade publishing platform engineered with a decoupled client-server architecture and strict layered design patterns.

- **Frontend:** React, Vite, TypeScript, Tailwind CSS, React Router v6, Axios (JWT Bearer Interceptors) — *Live on Vercel Edge Network.*
- **Backend & DB:** Node.js, Express.js, TypeScript, PostgreSQL (Neon Serverless), Prisma v7, Docker — *Containerized and running on Render.*
- **Key Engineering Challenges Solved:**
  - Overcame Render's ephemeral disk limitation by engineering a persistent media pipeline via Multer + Cloudinary CDN.
  - Implemented defensive payload normalization using Zod preprocess schemas to eliminate multipart/form-data type discrepancies.
  - Configured Vercel SPA rewrite rules to ensure seamless client-side deep routing without 404 drops.
- **Links:** [Live Demo](https://blog-frontend-theta-six.vercel.app) • [Case Study](https://www.berkaycelik.dev/en/projects/pulse) • [Portfolio](https://www.berkaycelik.dev/en)

### 🛠️ Engineering Principles & Core Focus

- 🏗️ **Clean & Layered Architecture:** Decoupling concerns across Controller, Service, and Repository layers to build maintainable, scalable, and loosely coupled systems.
- 🔒 **Security & Type Safety:** Enforcing end-to-end type safety, dual-token JWT authentication (Access & Refresh), Zod schema validation, RBAC, and rate limiting.
- 🤖 **AI-Augmented Engineering:** Leveraging AI not as a blind code generator, but as a thought partner and force multiplier for architectural verification, test case synthesis, and edge-case discovery.
- 🌐 **Systems & Networking Foundation:** Grounded in Cisco Network fundamentals (TCP/IP, DNS, HTTP protocol lifecycle) with a deep understanding of client-server interactions.
- 🤝 **Operational Ownership:** Channeling crisis management, effective communication, and team leadership experience from Decathlon Sports Leadership into agile software teams.
